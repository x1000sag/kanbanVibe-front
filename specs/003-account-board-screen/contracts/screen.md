# Контракт экрана: Своя доска

**Feature**: 003-account-board-screen
**Date**: 2026-11-26

Норма текста и вида для человека. Поля и коды — в [account-board.yaml](account-board.yaml). Сущности — в [data-model.md](../data-model.md).

Экран вызывает живой сервис по контракту полей и кодов. Фразы ниже не меняются: код ответа в текст не подставляется. Панель пробных переключателей, лист из четырёх отдельных сцен, холодный фон, смайлики в заголовках колонок и ссылка Read more на экран не входят.

## Состояния

Одновременно видно одно из состояний полотна.

| Состояние | Что видно | Чего нет |
|---|---|---|
| Гость | Тёплое полотно на весь экран, плитка, Board, круглая «+», «Войти», фраза «Войдите, чтобы открыть свою доску» | Колонок, карточек, тёмного поля вокруг полотна |
| Своя доска | Те же верх и «+», метка профиля, три колонки | Приглашения ко входу, чужих карточек |
| Данные недоступны после уже показанной доски | Последние карточки на месте и фраза «Данные сейчас недоступны» | Подмены доски тремя пустыми колонками |
| Данные недоступны до первого показа | Верхняя полоса, если вход уже есть, и та же фраза | Трёх колонок с «Пусто» |
| Нужно войти снова | Приглашение гостя и фраза «Нужно войти снова» | Карточек прежнего входа |

Пустая колонка на уже показанной доске — подпись «Пусто», не состояние ошибки.

Круглая кнопка без входа открывает окно входа и не создаёт карточку. С входом и уже показанной доской она открывает новую карточку. Доступное имя кнопки в обоих случаях — «Добавить карточку».

## Карточка

Белая, радиус 14px, внутренний отступ 20px, граница `oklch(0.9 0.01 80)`, тень `0 1px 2px oklch(0.2 0.02 50 / 0.06), 0 8px 24px oklch(0.2 0.02 50 / 0.05)`. При наведении сдвигается вверх на 2px, тень `0 12px 32px oklch(0.2 0.02 50 / 0.1)`. Название — Newsreader 500, около 1.35–1.55rem. Описание, если есть, 14px, цветом тихого текста. Внизу черта цвета границы, кнопка `Edit` с рамкой (12px, насыщенность 600, радиус 8px, фон `oklch(0.98 0.005 80)`) и дата 12px, если дата задана. Исполнителя, Read more и отдельной заметки нет.

Метки категорий — капс через CSS, 11px, насыщенность 600, радиус 6px:

| Категория | Фон | Текст |
|---|---|---|
| UX Design | `oklch(0.94 0.03 45)` | `oklch(0.42 0.06 45)` |
| UI Design | `oklch(0.94 0.03 290)` | `oklch(0.42 0.06 290)` |
| Testing | `oklch(0.94 0.03 155)` | `oklch(0.42 0.06 155)` |
| Project Management | `oklch(0.94 0.03 70)` | `oklch(0.42 0.06 70)` |
| Своя | `oklch(0.97 0.012 80)` | тихий текст |

Название категории написано текстом. Своя метка приглушённая и светлее готовых. Дата на карточке — день и короткий английский месяц, например `8 Jul`, цифры табличные.

Доступное имя `Edit` включает название карточки: `Edit, Design homepage mockup`.

Порядок в колонке — более ранняя выше. Перетаскивания нет.

## Окна

Одновременно открыто не больше одного. Окно белое, радиус 20px, отступ 28px, выше приглушённой доски. Поля и кнопки — радиус 10px, метки — 8px. Закрытие: крестик «Закрыть», кнопка отмены, щелчок по затемнению, Escape. Фокус входит в окно и возвращается к кнопке, которая его открыла.

Заголовки окон и крупное поле названия — Newsreader 500. Остальной текст окна — DM Sans.

- Новая карточка. Узкая надпись «Карточка». Для чтения с экрана — «Новая карточка». Поля: название с подсказкой «Название», описание, категория (четыре готовых и поле «Новая»), колонка тремя вариантами, дата с подписью «Дата», «Отмена», «Создать». Сначала выбраны UX Design и To Do. Поля можно менять с клавиатуры.
- Открытая карточка. Тот же порядок, значения текущие и не для правки. Для чтения с экрана — «Редактирование». Внизу «Удалить» и «Отмена». «Сохранить» нет.
- Вход. Уже окна. Плитка и Board, надпись «Доска», заголовок «Войти». Поля «Логин» и «Пароль», кнопка «Войти» на всю ширину, ссылка «Нет аккаунта — создать». В создании заголовок «Создать аккаунт», поле «Имя», кнопка «Создать аккаунт», ссылка «Уже есть аккаунт».
- Профиль. Крупная первая буква имени, надпись «Профиль», имя как заголовок. Поле «Имя на доске», логин только для чтения, свёрнутое «Сменить пароль». В раскрытии: текущий пароль, новый пароль, повтор. Внизу «Выйти», «Закрыть», «Сохранить». Доступное имя метки, которая открывает окно, — «Профиль, {имя}».

Пароль в окне после отправки не остаётся и в текст ошибки не копируется.

## Фразы

Одна ситуация — одна фраза. Код в фразу не подставляется.

| Ситуация | Фраза | Откуда |
|---|---|---|
| Пустое имя при создании | Нужно имя | экран, до запроса |
| Пустой логин в поле | Нужен логин | экран, до запроса |
| Пустой пароль в поле | Нужен пароль | экран, до запроса |
| Логин не принят при создании | Логин не подходит | `nick_invalid` |
| Пароль не принят | Пароль не подходит | `password_invalid` |
| Логин занят | Этот логин уже занят | `nick_taken` |
| Вход не удался | Не удалось войти | `sign_in_failed` |
| Доступ кончился | Нужно войти снова | `no_active_access` или 12 часов |
| Имя не принято | Имя не подходит | `display_name_invalid` |
| Текущий пароль неверен | Текущий пароль не подошёл | `password_change_rejected` |
| Повтор пароля не совпал | Пароли не совпадают | экран, запрос не уходит |
| Пустое название карточки | Нужно название | экран, запрос не уходит |
| Своя категория длиннее 32 | Категория не длиннее 32 символов | экран, запрос не уходит |
| Данные недоступны | Данные сейчас недоступны | `store_unavailable` |
| Обрыв вызова | Нет соединения | сеть, кода нет |
| Иной отказ запроса | Запрос не выполнен | `request_invalid`, `foreign_data`, незнакомый 4xx |
| Отказ службы | Не получилось выполнить действие. Повторите позже | 5xx кроме `store_unavailable` |
| Карточка не записалась | Карточка не сохранилась | `card_invalid` или `object_missing` на создании |
| Карточки уже нет | Карточки уже нет | `object_missing` на удалении |

`foreign_data` не показывает чужую доску и чужое имя.

## Движение

Обычная смена — 200 мс, `cubic-bezier(0.22, 1, 0.36, 1)`. При `prefers-reduced-motion: reduce` смена без сдвига, карточка не приподнимается.

## Клавиатура

Основные действия доступны без указателя: открыть и закрыть вход, заполнить и создать карточку, открыть профиль. Кольцо фокуса акцентного цвета. Ошибка поля написана словами, не только рамкой. Статус колонки и категории не сообщается только цветом.
